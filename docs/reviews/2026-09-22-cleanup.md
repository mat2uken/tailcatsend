- 現在の製品が呼ばない Go デーモン、旧形式のファイル・テキスト転送 API、旧ブラウザー API の別名を削除。現行のメッセージ単位のテキスト転送と NAME ファイルヘッダー、接続・キャンセル処理を保持した。

- Tauri と重複していた旧 desktop エントリー、未使用の型・依存宣言・サンプルを削除。テスト用通信実装は製品公開 API から外した。
- Web UI の Tauri 呼び出し、トースト終了処理、プライバシーページの CSS を共通化。未使用 CSS・画像・依存を削除した。
- 使用箇所がない Firebase Remote Config を Web/Rust/Kotlin/Swift と説明文から削除。Analytics、Crashlytics、収集設定の保存・切り替えは保持した。Android の telemetry は不要な JSON 往復変換を削除した。
- Release/TestFlight/Google Play の署名準備・ビルド番号生成をスクリプトへ集約。署名準備の内容は変更前の各 workflow と一致することを機械的に確認した。
- 古いデーモン用 E2E、未参照のビルド・配布ラッパーなど21ファイルを削除。現行 E2E の待機・ハッシュ・経路検査を共有した。明示的な WebRTC 指定時にも経路を検査するようにした。
- 追跡されていた古い UI 生成物を削除。配布時は既存 CI が現在のソースから生成する。ローカル検証出力と Python キャッシュを Git の対象外にした。
- Android の未参照レイアウト・重複テーマと、同梱されていない fixture に依存する swift-rs の旧テスト構成を削除。使用中の SwiftLinker と製品向けパッチは保持した。

## リポジトリ全体の追加精査

開始時点の管理対象345ファイルを、コード、設定、テスト、画像、文書、vendorの使用先まで分類した。上流Tailcat/Tailscaleのsubmodule本体は固定依存として扱い、独自bridge・patch・build接続を確認した。最終統合後のpass6と独立pass7は、連続して新しい安全な削減候補0件だった。最終ソース159ファイルのハッシュ一致も照合している。絶対に整理の余地がないという証明ではなく、現状の動作を維持する範囲で根拠のある候補を処理し終えたという結果である。

- 製品から使われていなかったRust更新crateを削除し、署名・更新先・API・rollback・欠損ファイルの必要な検証を現役のTypeScript更新テストへ集約。lockfileは16 packages減、追加0で、既存依存のversion更新なし。

- WebのGo callbackがclose後も接続と64KiBバッファ2個を保持する問題を再現し修正。共有dispatcherとJavaScriptのbind/WeakMapを使い、close時にGo側の保持を解除する。再入・二重close、cached method、保留中I/O、半閉鎖、部分I/Oを検証し、JS側の参照を残したままGo接続とlistenerが回収されることを確認した。
- scannerの未使用Rust wrapper/Error/依存と空module、最低対応OS未満の分岐を削除。登録後の実体はTauriのAndroid/iOS PluginManagerが所有することを使用中ソースで確認した。未参照画像10枚・XML2個（163,422 bytes）と不要生成処理を削除し、現用アイコン6枚のSHAは不変。最終APKのaapt2出力にも削除した名前は残らない。
